# كارتي 5G

مشروع مستقل لمنصة إدارة وبيع بطاقات الإنترنت. المستودع يحتوي على واجهات عربية RTL، منطق مجال واختبارات وحدات، ومخططات Supabase أولية للمراجعة. **ليس MVP تشغيليًا بعد**: لا توجد بيانات Supabase، لم تطبق migrations، ولا توجد آلية تهيئة أول مالك للمنظمة.

## المتطلبات والتشغيل

- Node.js 20.9 أو أحدث؛ جرى الفحص على Node.js 24.19.0.
- pnpm 11.19.0؛ استخدم `pnpm` فقط.

```bash
pnpm install --frozen-lockfile
pnpm dev
```

أوامر الجودة:

```bash
pnpm lint
pnpm typecheck
pnpm test
pnpm build
```

## البنية

```text
src/app/                 صفحات App Router وServer Actions
src/components/          عناصر الواجهة المشتركة
src/config/              تعريفات العرض والمسارات
src/lib/domain/          قواعد مجال نقية
src/lib/imports/         تحليل CSV وتصنيف الصفوف
src/lib/security/        تشفير بيانات البطاقة وبصمتها
src/lib/supabase/        عميل Supabase خادمي وإعداداته
src/types/               أنواع المجال
supabase/migrations/     مخطط PostgreSQL وسياسات RLS وRPCs
tests/                   اختبارات وحدات محلية
docs/                    المعمارية والنطاق والأمن والقرارات والتشغيل
```

توضح الصفحات النصية غير المكتملة حالتها ولا تدعي وجود بيانات حقيقية. المسارات `/login` و`/register` تربط Server Actions بـSupabase عندما تتوفر الإعدادات؛ لا تعمل دونها. أضيف Server Action لاستيراد CSV: يتحقق من المستخدم وعضويته، ثم يحسب HMAC ويشفّر على الخادم ويرسل الصفوف عبر مفتاح خدمة server-only. بقية واجهات العمليات لا تزال غير مكتملة.

## Supabase

انسخ `.env.example` محليًا إلى `.env.local` وضع القيم من مشروع **تطوير/اختبار** معتمد. المتغيرات السرية المطلوبة لتخزين البطاقات هي `CARD_ENCRYPTION_KEY` و`CARD_FINGERPRINT_KEY` (32 بايت لكل منهما، Base64). مسار الاستيراد يحتاج أيضًا `SUPABASE_SERVICE_ROLE_KEY` على الخادم فقط؛ لا تضعه في `NEXT_PUBLIC_*` ولا في المتصفح أو Git.

يلزم أن يكون مزود البريد/تأكيد البريد معطلًا للمشروع لأن الدخول يمر عبر البريد الداخلي `رقم الهاتف@mutahidun.app` دون SMS أو بريد فعلي. راجع [قرارات النطاق](docs/decisions.md) قبل التطبيق. لا تطبق migrations على Production. تهيئة أول Owner متاحة كـRPC لمرة واحدة لا ينفذها إلا `service_role`، ولا توجد بيانات مستخدم أو منظمة مضمنة في المصدر.

توجد migrations في `supabase/migrations/` لكنها لم تُطبّق أو تُختبر على PostgreSQL/Supabase. يلزم بيئة اختبار معتمدة واختبارات RLS قبل اعتبارها صالحة للنشر. التحويلات المعلقة تنتهي بعد 24 ساعة؛ يمكن لمالك/مدير المنظمة تشغيل RPC التسوية، وهي تقفل السجلات وتحرر الحجز وتسجل ledger/audit دون حذف.

## حدود النسخة الحالية

- منجز محليًا: تحقق رقم الهاتف، mapping الداخلي، تشفير AES-256-GCM، HMAC للتكرار، محلل CSV أولي، اختيار FIFO وقواعد انتقال نقية.
- جزئي: واجهات الحساب ومساحات الأدوار؛ اتصال Supabase محضر لكنه غير مهيأ.
- مؤجل/محجوب: تشغيل الشبكات والمنتجات والدفعات والمخزون والتحويل والبيع والتسليم وكروتي والتدقيق والتقارير.

راجع `docs/mvp-scope.md` و`docs/decisions.md` للحالة التفصيلية.
